# Digital folders and offline references

A **Digital Folder** is a Silo collection made from references to originals. It is not a new folder on disk and it does not duplicate the photos.

## Create a collection

1. In the Files sidebar, choose **+** beside **Digital Folders**.
2. Give the collection a useful name.
3. Select the files you want from the current Files view and use the collection's add/reference action.
4. Open the collection from the sidebar to review its contents.
5. Remove a reference when the collection no longer needs it. The original stays in its source.
6. Rename, reorder or remove a Digital Folder as an organizational change. These operations do not rename, move or delete the original media.

Selecting a smaller source set before adding files makes it easier to build a collection from the intended device or archive.

## How an offline reference behaves

Silo stores a local reference to the source item and can preserve its indexed metadata. If the original lives on an external drive or a phone that is disconnected, the reference may remain in the collection but Silo cannot promise that the original can be opened or exported until the source is available again. A cached thumbnail or search record is not the original file and should not be treated as a backup.

Cloud references have a similar dependency: browsing or previewing a remote item may require a valid session and network access. For offline access to the original, keep a verified local copy or a separate backup.

## Digital folder vs physical folder

| Action | Changes original file? | Creates a copy? |
|---|---:|---:|
| Add/remove a Digital Folder reference | No | No |
| Set a virtual name | No | No |
| Create a folder in a writable source | Creates a real directory | No |
| Move a file | Yes, changes its location | No |
| Export/download/phone save | No source change | Yes |

Always use a physical copy or a verified backup when you need independent offline storage.
