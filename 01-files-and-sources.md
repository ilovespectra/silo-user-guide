# Files and sources

**Files** is the main browser. Silo treats a local folder, removable drive, phone, Google Drive and a set of Google Photos Picker selections as sources that can be included in the same view.

## Add and browse sources

1. In **Files**, use **+** beside **Sources** to add a folder, or use the source-specific controls for phones and Google accounts.
2. Wait for the source to be checked and shown as available. A disconnected or unreadable source can remain in the list with a status explaining why it cannot be opened.
3. Use the checkbox to include or exclude an available source from the combined view. This changes the current browsing scope; it does not disconnect the source or delete files.
4. Use the row chevron to open one source by itself. **Select all** and **Select none** quickly change the combined scope. Source selection is remembered between launches.
5. Use **Refresh** after reconnecting a drive or device to update availability.

## Browse one folder or many

- **Collapsed sources** show one folder per selected source.
- **Explode** flattens nested files from the selected sources into one combined view. It can be useful for finding a file when you do not remember which subfolder contains it.
- Narrow the selected sources before exploding a large collection.
- **Back**, **Forward**, **Parent** and **Refresh** navigate the current browsing context.

## Grid, list and filters

- **Grid** emphasizes thumbnails; **List** emphasizes file details.
- Adjust **Thumbnail size** to fit more or fewer cards on screen.
- **Sort & Filter** includes media/file type, year, people and location filters, plus sort order. Available filters depend on indexed metadata.
- The **Show** control can limit the visible file category. Select filters to focus the current results; they do not move files.
- File cards can show preview, detected-person and favorite indicators. A missing thumbnail does not necessarily mean the original is missing; indexing or preview generation may still be in progress.

## Open and act on a file

Select a file to enable applicable toolbar actions. Depending on source and file type, Silo can open a larger viewer, zoom images, play audio/video, create a folder, move a file, set a virtual name or edit search keywords.

- **Move** changes the file's actual location. Check the source and destination before confirming.
- **Set virtual name** changes the label Silo uses in its interface and search; it does not rename the underlying file.
- **New folder** creates a real folder in the current writable source.
- **Favorite** changes Silo's organizational marker, not the file.
- Remote sources may support fewer operations than local folders. Google Drive supports its own rename, trash, folder and upload operations; Google Photos Picker content is read-only.

## Tips

- Add a small representative folder first to learn the layout.
- Use source names and availability labels to distinguish local, phone and cloud items.
- Selecting a source does not guarantee that its search, people or location indexes are finished.
- If a source shows disconnected/unreadable, reconnect it and refresh. For Time Machine access, see [Full Disk Access](11-settings-and-privacy.md#time-machine-access).
